# FACE BALANCE YOGA — 8種目アニメーション素材（試作 v0.1）

ChatGPTで制作した顔ヨガの **8種目分の試作素材** を Work に渡すための一括パッケージです。各種目に元のアニメーションGIFと、無音H.264 MP4を同梱しています。

## 重要な注意
- **これは開発検品用の試作素材であり、医療・ヨガ指導上の監修は未完了です。** とくに顎・舌・頬・首の動作は、実演の正確性と安全性を監修してください。
- 機械生成の短いGIFをMP4に変換したもので、**滑らかな連続実写動画ではありません**。映像表現にはコマ間の不連続があり得ます。
- 音声は入っていません。既存Yoga AIの音声・字幕・タイマーを維持し、画面表示の同期を検証してください。
- 生成GIFには文字が焼き込まれています。アプリ側の字幕と重複・不一致になる可能性があるため、必要なら映像だけの再制作を提案してください。
- 実際の安全確認・監修が済むまでは、一般公開・mainマージ・本番環境への反映はしないでください。

## ファイル構成
- `gif/`：画像生成した元のアニメーション（元ファイルは拡張子`.png`でしたが実データはGIFなので適切に`.gif`へ修正）
- `mp4/`：それぞれを無音H.264、30fps、`yuv420p`、Fast Startで変換したMP4
- `manifest.json`：種目名、再生尺、コマ数、ファイル名、検査用SHA256

## 首 Griva Gentle の再生順序（指定）
**正面 → 右 → 正面 → 左 → 正面 → 右 → 正面 → 左 → 正面 → 右 → 正面 → 左 → 正面 → 下向き。**
全14コマです。`07_griva_gentle_corrected` のみを使用し、旧版の `首のやさしいストレッチ手順.png` は使わないでください。ここでいう右・左は **実演者本人の左右** です。必要に応じて実機で左右の向きを確認してください。元の14コマ素材の順序を目視でも確認し、足りない動作や不自然な動作があれば修正前提としてください。
