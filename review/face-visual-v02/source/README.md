# FACE BALANCE YOGA｜7種目 スムーズ化レビュー v0.2

## 含まれるもの
- 7本の無音MP4、30fps、480×640、H.264（スマホブラウザ対応を想定）
- 各種目の検品用サムネイル（*_QC.jpg）
- manifest.json（尺、元画像のキーフレーム対応、SHA256）

## 制作手法と限界
以前の同一女性モデルのAI生成キーフレームを使い、字幕や回数表示を含む上下部分を取り除いて、オプティカルフローにより中間コマを補いました。これは実写撮影・高精度人物動画生成ではありません。顔、舌、顎の形が途中で不自然に歪む場合があります。首は大きい角度の補間で顔が二重になるため、モーションブラー付きコマ切替に変更しています。首はまだ本当の意味で滑らかな連続動作になっておらず、再制作が必要です。医療・指導内容の監修が終わるまでは教材として公開しないでください。

## 既存のLip O–Smileについて
ユーザーが承認したLip O–Smileはこの7本には含めていません。既存の完成方向（「オ」の形を2秒保持したうえで自然な笑顔へ）を維持してください。

## Workへの導入条件
この7本は**動作改善の候補・視覚レビュー用**です。現在のAI先生の音声・字幕・数値タイマーを変更したり、勝手にMP4の長さへ合わせたりしないこと。各種目の進行キューを元に、動画のキーフレーム範囲を表示して同期する仕様をWorkで検証し、Galaxy／LINE内ブラウザで実聴・左右の整合を確認すること。動作の不正確な動画は採用せず、既存SVGをフォールバックとして残してください。

特に **Griva Gentle**：正面→本人の右→正面→本人の左×3往復→正面→下向き（最後に正面復帰を追加しない）。元素材上の左右の見え方が利用者自身の左右と一致するか確認が必要です。

**Jaw Release**：口を大きく開く原コマは使用せず。**Simhasana**：舌を極端に伸ばした原コマは使用せず。**Face Relax**：不要な開口のコマは使用せず。**Kapola**：息を止める指示なし。

PR #27〜#32はDraft維持、本番公開・mainマージは行わないでください。音声／タイマーを変更する必要がある場合は別途承認を取ってください。
