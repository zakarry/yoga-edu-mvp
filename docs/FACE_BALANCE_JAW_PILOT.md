# FACE BALANCE YOGA Jaw Release 試作

開発サーバーで `/jaw-release.html` を開く。端末のローカル日本語音声が必要。既存のPractice登録契約で種目・案内・フェーズを定義し、既存の製品カタログや実践記録から分離する。

説明の正常終了後に数値タイマーを開始する。5秒の観察と4秒の解除・休息を5周で45秒。実践中は字幕・模式図・回数と数値を同じ時計で更新する。試作は説明のみを読み上げ、実践中の数字は画面に表示する。監修後に実践キュー用の収録音源と同期を検品する。

5分コース案は Jaw Release → Kapola Awareness → Tongue Mobility → Smile Balance → Face Relax。原本の実践枠で合計300秒。説明・切替は別枠。構成と安全条件は監修待ち。

監修待ちの項目は顎の開口範囲、安全文言、端末ごとの発音と末尾、カポーラの呼吸、シンハーサナの原典との差、グリーヴァの分類。左右差改善や小顔の効果をうたわない。

検証は型チェック、Build、全回帰、既存ブラウザ回帰とJaw専用ブラウザ回帰を分ける。Jawのブラウザテストは再生イベントの模擬で、発音や実端末の再生を保証しない。
